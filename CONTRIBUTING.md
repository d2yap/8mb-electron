# Contribution Guidelines

# Contributing to 8mb-electron

Thank you for your interest in contributing! We welcome contributions of all kinds ~ bug reports, feature requests, documentation improvements, and code changes. ALL help is very welcome, no matter how small!

## Getting started

- Fork the repository and create a branch from `main` named using the pattern `feat/short-description` or `fix/short-description`. (Basically any prefix then the description of the fork)
- Install dependencies: `npm install`.
- Run the app in development: `npm run dev` (or the project's existing dev script).

## Reporting issues

- Search existing issues before opening a new one.
- When filing an issue, include a clear title, steps to reproduce, expected vs actual behavior, and environment details (OS, etc).

## Submitting a Pull Request

1. Create a descriptive branch and commit history.
2. Push your branch to your fork and open a Pull Request against `main`.
3. In the PR description include what you changed, why, and any screenshots or logs if relevant. Link related issues using `#<issue-number>`.

## License

By contributing, you agree that your contributions will be licensed under this project's existing license.

## Need help?

If you're unsure where to start, open an issue marked `help wanted` or ask for guidance in an issue and a maintainer will try to point you to a good first task.
